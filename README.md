# RecipeShare - Социална платформа за споделяне на кулинарни рецепти 🍳

RecipeShare е пълнофункционално уеб приложение (Full-Stack), изградено със стека MERN. Платформата позволява на потребителите да споделят своите любими рецепти, да следват други автори и да взаимодействат с кулинарната общност чрез коментари и оценки. Системата включва разширен административен панел за модерация на съдържанието.

## ✨ Основни функционалности

- **Потребителска автентикация:** Сигурна регистрация и вход чрез JWT (JSON Web Tokens) с автоматично управление на изтекли сесии.
- **Управление на рецепти:** Пълен CRUD цикъл (създаване, преглед, редактиране и изтриване) с прикачени изображения и видео уроци.
- **Умно търсене и филтриране:** Разширено търсене по ключова дума, вид кухня, диета, трудност и тип ястие, както и филтриране по включващи/изключващи съставки.
- **Социални функции:** Система за следване на автори, персонализирана емисия (Feed) в реално време, рейтингова система със звезди и дискусионни секции.
- **Система за модерация:** Докладване на съдържание и специализирано администраторско табло за одобряване на рецепти и управление на потребители.
- **Адаптивен дизайн:** Модерен "Bold" интерфейс, напълно оптимизиран за мобилни устройства и десктоп компютри.

## 🛠️ Технологичен стек

- **Фронтенд:** React 18 (Vite), Tailwind CSS, Lucide Icons, Shadcn/UI.
- **Бекенд:** Node.js, Express.js.
- **База данни:** MongoDB Atlas (Mongoose).
- **Облачни услуги:** Cloudinary API (за хостинг на изображения).
- **Тестване:** Jest, Supertest.

## 🚀 Инсталация и стартиране

### Системни изисквания
- Node.js (v16 или по-висока)
- Конфигурационен файл (.env) с ключове за MongoDB и Cloudinary

### Инструкции за инсталиране

1. **Клониране на хранилището:**
   ```bash
   git clone https://github.com/yourusername/recipe-share.git
   cd recipe-share
   ```
2. **Настройка на Бекенд:**
   ```bash
    cd backend
    npm install
   ```
  Създайте .env файл в папка backend и добавете своите ключове:
```sh
PORT=5000
MONGO_URI=вашият_mongodb_connection_string
JWT_SECRET=вашият_таен_ключ
CLOUDINARY_CLOUD_NAME=вашето_име
CLOUDINARY_API_KEY=вашият_ключ
CLOUDINARY_API_SECRET=вашата_тайна
```

  Стартирайте сървъра:
```bash
npm start
```
3. **Настройка на Фронтенд:**
   ```bash
    cd ../frontend
    npm install
    npm run dev
    ```
